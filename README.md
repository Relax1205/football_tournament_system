# Football Tournament System

Монорепозиторий учебного проекта **«Система учета футбольных турниров»**.

## Структура

```text
frontend/       # Next.js frontend
docs-stub/      # TypeDoc-стаб для документации
```
Там лежат:

- интерфейс приложения
- документация пользователя
- QA-артефакты
- Selenium UI-тесты

## Быстрый запуск

```bash
cd frontend
nvm use 22
npm install
npm run dev -- --hostname localhost --port 3010
```
