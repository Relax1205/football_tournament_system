# Football Tournament System

Веб-приложение для управления футбольными турнирами. Система покрывает основные сценарии предметной области: создание турниров, приём заявок команд, ведение составов игроков, формирование расписания, ввод результатов, расчёт турнирной таблицы и выгрузку отчётов.

Проект состоит из двух частей:

- `frontend` на `Next.js 14`
- `backend` на `Express + Prisma + PostgreSQL`

## Быстрый запуск через Docker

Рекомендуемый способ запуска всего проекта:

```bash
npm run dev
```

или напрямую:

```bash
docker compose up --build
```

После старта будут доступны:

- `http://localhost:3000` — frontend
- `http://localhost:4000` — backend
- `http://localhost:4000/health` — healthcheck backend
- `localhost:5433` — PostgreSQL

Остановка:

```bash
npm run stop
```

Полный сброс контейнеров и базы:

```bash
npm run reset
```

## Локальный запуск без Docker

Если нужен именно раздельный запуск сервисов:

### 1. Поднять PostgreSQL

Можно использовать локальный PostgreSQL или контейнер только с базой:

```bash
docker compose up -d db
```

### 2. Запустить backend

```bash
cd backend
npm install
npx prisma generate
npx prisma db push
npx prisma db seed
npm run dev
```

Пример `backend/.env`:

```env
DATABASE_URL=postgresql://postgres:postgres@localhost:5433/football_tournament_db?schema=public
PORT=4000
JWT_SECRET=dev-secret-key
JWT_EXPIRES_IN=7d
```

### 3. Запустить frontend

Во втором терминале:

```bash
cd frontend
npm install
npm run dev
```

Пример `frontend/.env`:

```env
API_PROXY_TARGET=http://localhost:4000
```

## Полная ручная проверка всего функционала

Ниже — удобный сценарий, по которому можно пройти приложение вручную от начала до конца.

### 1. Проверка запуска

1. Выполни `npm run dev`.
2. Открой `http://localhost:3000`.
3. Убедись, что открывается главная страница.
4. Открой `http://localhost:4000/health`.
5. Ожидаемый результат: backend отвечает JSON со статусом `ok`.

### 2. Проверка авторизации

1. Перейди на `/login`.
2. Войди под `org@tournament.ru / Test123!`.
3. Ожидаемый результат: открывается кабинет.
4. Выйди.
5. Попробуй войти с неверным паролем.
6. Ожидаемый результат: показывается ошибка авторизации.

### 3. Проверка организатора

Вход:

- `org@tournament.ru / Test123!`

Что проверить:

1. Открой раздел `Турниры`.
2. Убедись, что список турниров отображается и фильтры работают.
3. Создай новый турнир.
4. Ожидаемый результат: новый турнир появляется в таблице.
5. В том же разделе сформируй календарь для созданного турнира.
6. Ожидаемый результат: после генерации меняется число матчей.
7. Перейди в кабинет на блок управления заявками и командами.
8. Проверь, что видны заявки со статусами `Одобрена`, `На рассмотрении`, `Отклонена`.
9. Одобри или отклони одну из заявок.
10. Ожидаемый результат: статус меняется без перезагрузки страницы.
11. Создай новую команду через CSV-файл состава.
12. Ожидаемый результат: команда создаётся, появляется сообщение об успешном импорте.
13. Открой раздел `Матчи`.
14. Найди матч в статусе `Требует подтверждения`.
15. Нажми `Подтвердить`.
16. Ожидаемый результат: статус матча меняется на `Подтверждён`.
17. Открой раздел `Турнирная таблица`.
18. Нажми `Пересчитать`.
19. Ожидаемый результат: появляется сообщение об успешном пересчёте.
20. Нажми `Экспорт в Excel`.
21. Ожидаемый результат: скачивается `.xlsx` файл.

### 4. Проверка тренера

Вход:

- `coach@tournament.ru / Test123!`

Что проверить:

1. В кабинете открой блок `Подать заявку`.
2. Создай новую заявку на открытый турнир.
3. Ожидаемый результат: появляется сообщение, что заявка отправлена организатору.
4. В кабинете открой блок `Добавить игрока`.
5. Добавь игрока в свою команду.
6. Ожидаемый результат: появляется сообщение об успешном добавлении.
7. Перейди в раздел `Матчи`.
8. Убедись, что расписание доступно только для просмотра.
9. Перейди в `Турнирную таблицу`.
10. Ожидаемый результат: таблица видна, кнопок административного управления нет.

### 5. Проверка судьи

Вход:

- `referee@tournament.ru / Test123!`

Что проверить:

1. Открой раздел `Матчи`.
2. Убедись, что в форме выбора доступны только редактируемые матчи.
3. Выбери матч, измени счёт, игрока, минуту и комментарий.
4. Нажми `Сохранить результат`.
5. Ожидаемый результат: появляется сообщение `Результат сохранён и отправлен организатору`.
6. Повтори сценарий, но введи минуту `150`.
7. Ожидаемый результат: показывается ошибка валидации минуты.
8. Нажми `Сгенерировать протокол`.
9. Ожидаемый результат: скачивается PDF-протокол матча.

### 6. Проверка администратора

Вход:

- `admin@tournament.ru / Test123!`

Что проверить:

1. Открой кабинет.
2. Убедись, что доступен блок управления ролями.
3. Измени роль одного из пользователей.
4. Ожидаемый результат: роль обновляется в таблице.
5. Проверь доступ к разделам `Турниры`, `Матчи`, `Команды и игроки`, `Турнирная таблица`.

### 7. Проверка болельщика

Вход:

- `fan@tournament.ru / Test123!`

Что проверить:

1. Открой `Матчи`.
2. Ожидаемый результат: раздел доступен только в режиме просмотра.
3. Убедись, что нет формы ввода результата матча.
4. Убедись, что можно открыть протокол матча.
5. Открой `Турнирную таблицу`.
6. Ожидаемый результат: таблица доступна без административных кнопок.
7. Открой `Команды и игроки`.
8. Ожидаемый результат: можно смотреть статистику игроков, но нельзя редактировать данные.

### 8. Проверка турнирной таблицы

1. Открой `Турнирная таблица`.
2. Убедись, что по умолчанию выбран `RTU Cup 2026`.
3. Проверь поиск по команде.
4. Проверь сортировку по месту, очкам и названию команды.
5. Ожидаемый результат: строки таблицы корректно перестраиваются.

### 9. Проверка экспорта и локализации

1. В `Матчах` проверь экспорт PDF.
2. В `Турнирной таблице` проверь экспорт Excel.
3. Убедись, что даты показываются в формате `ДД.ММ.ГГГГ`.
4. Убедись, что статусы в интерфейсе русифицированы.

## Краткий чек-лист по разделам

- `Главная` — страница открывается
- `Вход` — корректный и некорректный логин работают как ожидается
- `Кабинет` — сценарии меняются по ролям
- `Турниры` — создание, фильтрация, генерация расписания
- `Матчи` — просмотр, ввод результата, подтверждение, PDF
- `Турнирная таблица` — поиск, сортировка, пересчёт, Excel
- `Команды и игроки` — статистика игроков и фильтры
- `Кабинет / управление командами` — заявки, создание команды, импорт CSV, добавление игрока

## Полезные команды

Из корня репозитория:

```bash
npm run dev
npm run stop
npm run reset
npm run logs
```

Назначение:

- `npm run dev` — поднять весь проект через Docker
- `npm run stop` — остановить контейнеры
- `npm run reset` — сбросить контейнеры и том базы
- `npm run logs` — смотреть логи сервисов

## Если что-то не запускается

Проверь:

- запущен ли Docker Desktop
- свободны ли порты `3000`, `4000`, `5433`
- отвечает ли `http://localhost:4000/health`
- не остались ли старые контейнеры от предыдущих запусков

Если нужен полный чистый старт:

```bash
npm run reset
npm run dev
```
