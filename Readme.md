# Система учёта футбольных турниров

Веб-приложение для автоматизации организации и проведения любительских футбольных соревнований. Разработано в рамках дисциплины **«Системная и программная инженерия»** (РТУ МИРЭА, 2026 г.).

## Основные возможности
- **Авторизация и RBAC**: Разграничение прав (Администратор, Организатор, Судья, Тренер, Игрок/Болельщик).
- **Управление турнирами**: Создание турниров, добавление команд и игроков, массовая загрузка данных.
- **Генерация расписания**: Автоматическое формирование календаря матчей по алгоритму круговой системы.
- **Турнирная таблица**: Автоматический расчёт очков, побед/ничьих/поражений, разницы голов с сортировкой по правилам ФИФА.
- **Ввод результатов**: Интерфейс для судьи с валидацией событий (голы, карточки, минуты 1–120).
- **Отчётность**: Генерация протокола матча (PDF) и экспорт таблицы (Excel).
- **Контейнеризация**: Поддержка развёртывания через Docker & Docker Compose.

## Запуск проекта
### Предварительные требования
- Node.js ≥ 20.x
- PostgreSQL ≥ 14
- npm или yarn

### 1. Клонирование и установка зависимостей
git clone <ваш-репозиторий>
cd football_tournament_system

# Установка зависимостей бэкенда
cd backend
npm install

# Установка зависимостей фронтенда
cd ../frontend
npm install

### 2. Настройка переменных окружения
# Пример backend/.env:
PORT=4000
NODE_ENV=development
DATABASE_URL="postgresql://postgres:Schokk2005@127.0.0.1:5432/football_tournament_db?schema=public"
JWT_SECRET="ваш_секретный_ключ_минимум_32_символа"
JWT_EXPIRES_IN="7d"

# Пример frontend/.env.local:
NEXT_PUBLIC_API_URL="http://localhost:4000/api"

### 3. Инициализация БД
cd backend
npx prisma migrate dev --name init
npx prisma db seed

### 4. Запуск серверов
В двух терминалах:
cd backend/frontend
npm run dev

## Тестирование
