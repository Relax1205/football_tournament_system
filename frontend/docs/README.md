# Документация frontend

В этой папке собраны артефакты, которые соответствуют работам по документации и тестированию для роли `Студент 2 (Frontend & QA Lead)`.

## Разделы

- `wiki/` — заготовка пользовательской документации в формате Markdown для последующей публикации в GitHub Wiki.
- `testing/` — тест-кейсы, чек-лист, матрица требований и программа испытаний на основе отчётов №11–12.

## Статус

- Пользовательская документация: подготовлена как локальный набор wiki-страниц.
- QA-документация: подготовлена на основе требований и текущего frontend MVP.
- Презентация: не входит в текущий объём работ.
