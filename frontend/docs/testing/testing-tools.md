# Инструменты тестирования

Этот документ фиксирует инструменты из отчёта №11 и их применение к текущему проекту.

## Ручное функциональное тестирование

- Chrome
- Firefox
- Safari
- Edge

Назначение: проверка пользовательских сценариев и кроссбраузерности.

## Автоматизированное тестирование UI

- Selenium WebDriver

Назначение: автоматизация повторяющихся сценариев входа, проверки ролей и базовых пользовательских потоков.

## Производительность

- Lighthouse

Назначение: замер времени загрузки и базовых метрик интерфейса.

## Доступность

- axe DevTools
- WAVE

Назначение: проверка соответствия базовым требованиям доступности.

## API и backend

- Postman

Назначение: пригодится после интеграции frontend с реальным backend.

## Ограничение текущего этапа

На текущем frontend MVP часть инструментов оформлена как план и инфраструктурная подготовка. Полноценное применение Postman, OWASP ZAP, JMeter и проверок БД начнётся после подключения backend.
