# Checklist

Чек-лист подготовлен по отчёту №11 и адаптирован под текущий frontend.

## Авторизация и доступ

- [ ] успешный вход по корректным данным
- [ ] ошибка при неверном пароле
- [ ] редирект в личный кабинет после входа
- [ ] ограничение доступа к защищённым страницам
- [ ] скрытие действий без прав доступа

## Турниры

- [ ] отображается список турниров
- [ ] работает поиск по названию
- [ ] работает фильтр по статусу
- [ ] работает сортировка
- [ ] турнир создаётся с валидными данными
- [ ] ошибки валидации отображаются рядом с полями

## Матчи

- [ ] отображается список матчей
- [ ] работает поиск по команде и стадиону
- [ ] работает фильтр по статусу
- [ ] судья может отправить результат
- [ ] организатор может подтвердить результат
- [ ] недопустимая минута события блокирует отправку формы

## Команды и заявки

- [ ] отображается таблица команд и игроков
- [ ] работает сортировка статистики игроков
- [ ] тренер может отправить заявку
- [ ] организатор может одобрить заявку
- [ ] организатор может отклонить заявку

## Адаптивность и UX

- [ ] интерфейс читается на `320px`
- [ ] кнопки и поля доступны на мобильном экране
- [ ] навигация не ломается на планшете
- [ ] страницы корректно открываются на десктопе
