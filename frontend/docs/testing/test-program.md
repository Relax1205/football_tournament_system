# Программа и методика испытаний

Документ подготовлен на основе практической работы №12 и адаптирован под frontend проекта.

## 1. Объект испытаний

Веб-интерфейс системы учёта футбольных турниров, реализованный на `Next.js + React + TypeScript`.

## 2. Цель испытаний

- проверить соответствие frontend функциональным требованиям
- подтвердить корректность ролевого доступа
- оценить удобство использования и адаптивность интерфейса
- подготовить основу для регрессионного UI-тестирования

## 3. Среда испытаний

- Node.js 22 LTS
- npm
- браузеры: Chrome, Firefox, Safari, Edge
- разрешения: `320px`, `768px`, `1440px`

## 4. Виды испытаний

### Функциональные испытания

- авторизация
- создание турнира
- ввод результатов матча
- подача заявки на участие
- просмотр таблицы и статистики

### Испытания на доступ и роли

- проверка скрытия действий без прав
- проверка доступа к защищённым маршрутам

### Испытания на удобство использования

- читаемость интерфейса
- логичность навигации
- корректность текстов ошибок

### Испытания на адаптивность

- мобильный экран `320px`
- планшет
- десктоп

### Испытания на производительность

- время открытия ключевых страниц
- отсутствие заметных блокировок интерфейса

## 5. Инструменты

- ручное тестирование в браузерах
- DevTools для проверки адаптивности
- Lighthouse для базовых замеров производительности
- Selenium WebDriver как следующий этап автоматизации UI-тестов

## 6. Порядок проведения

1. Запустить локальный frontend.
2. Выполнить позитивные сценарии по test cases.
3. Выполнить негативные сценарии валидации и доступа.
4. Проверить отображение на трёх контрольных ширинах.
5. Зафиксировать результаты в чек-листе.

## 7. Критерии приёмки frontend

- основные страницы открываются без runtime errors
- роли применяются корректно
- формы валидируются на клиенте
- интерфейс отображается корректно на мобильном и десктопе
- пользовательская документация и QA-артефакты присутствуют в репозитории
