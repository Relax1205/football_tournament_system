# Football Tournament System Wiki

Добро пожаловать в пользовательскую документацию системы учёта футбольных турниров.

## Для кого эта документация

Система предназначена для следующих ролей:

- Администратор
- Организатор турнира
- Судья матча
- Тренер команды
- Зритель

## Основные возможности

- вход в систему по роли
- просмотр личного кабинета
- работа с турнирами и расписанием
- ввод и подтверждение результатов матчей
- просмотр турнирной таблицы
- просмотр статистики игроков
- подача заявок на участие
