# Турнирная таблица и статистика

## Турнирная таблица

Раздел отображает положение команд в турнире и основные показатели:

- место
- команда
- игры
- победы
- ничьи
- поражения
- голы
- разница голов
- очки

## Сортировка

В текущем frontend доступны просмотр и базовая работа с таблицей. Полная сортировка по правилам ФИФА должна контролироваться серверной логикой и тестами.

## Статистика игроков

Тренер и организатор могут просматривать статистику игроков по основным показателям:

- голы
- жёлтые карточки
- красные карточки

Список можно сортировать по показателям.
