# Турниры

## Возможности раздела

- просмотр списка турниров
- поиск по названию
- фильтрация по статусу
- сортировка списка
- создание нового турнира

## Поля формы создания турнира

- название турнира
- формат
- дата начала
- дата окончания
- количество групп
- стартовый статус

## Правила валидации

- название должно содержать минимум 4 символа
- дата окончания не может быть раньше даты начала
- количество групп должно быть от 1 до 8

## Ожидаемый результат

После успешного сохранения турнир появляется в общем списке.
