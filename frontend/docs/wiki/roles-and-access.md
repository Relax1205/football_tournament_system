# Роли и доступ

## Роли в системе

### Администратор

- назначает роли пользователям
- контролирует права доступа

### Организатор

- создаёт турниры
- подтверждает результаты матчей
- работает с заявками команд

### Судья

- вводит результаты матча
- добавляет события матча
- отправляет данные на подтверждение

### Тренер

- просматривает состав и статистику команды
- отправляет заявку на участие

### Зритель

- просматривает публичные разделы
- не может редактировать данные

## Принцип разграничения прав

Интерфейс скрывает или блокирует действия, которые не разрешены текущей роли. Например, зритель не может редактировать результаты матча, а подтверждение результата доступно организатору.
