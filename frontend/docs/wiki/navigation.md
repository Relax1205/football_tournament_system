# Навигация

## Основные разделы интерфейса

- `Главная` — обзор системы, быстрый переход к сценариям.
- `Вход` — авторизация пользователя по роли.
- `Кабинет` — персональная панель действий после входа.
- `Турниры` — список турниров, фильтры и форма создания.
- `Матчи` — расписание матчей и ввод результатов.
- `Таблица` — турнирная таблица и позиции команд.
- `Команды` — статистика игроков, заявки на участие и управление ролями.

## Порядок работы

1. Войти в систему.
2. Перейти в нужный раздел из верхней навигации.
3. Выполнить действие, которое доступно текущей роли.
4. Проверить изменение статуса или данных в таблице.
