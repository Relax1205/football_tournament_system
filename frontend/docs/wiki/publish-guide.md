# Публикация в GitHub Wiki

## Что уже готово

В каталоге `docs/wiki/` подготовлены Markdown-страницы, которые можно перенести в GitHub Wiki проекта.

## Минимальный порядок публикации

1. Открыть вкладку `Wiki` в репозитории GitHub.
2. Создать главную страницу `Home`.
3. Перенести содержимое из локального файла `Home.md`.
4. Создать остальные страницы по именам файлов из папки `docs/wiki/`.
5. Добавить содержимое `_Sidebar.md` в sidebar wiki.

## Рекомендуемые страницы

- Home
- navigation
- roles-and-access
- login-and-dashboard
- tournaments
- matches-and-results
- teams-and-applications
- standings-and-statistics
- faq
- troubleshooting

## Важно

Wiki в текущей ветке подготовлена как локальный набор страниц. Публикация в GitHub выполняется отдельно через интерфейс репозитория или отдельный wiki-репозиторий.
