# Вход и личный кабинет

## Вход в систему

1. Откройте страницу входа.
2. Введите email и пароль.
3. Нажмите кнопку входа.
4. После успешной авторизации система откроет личный кабинет.

## Что происходит после входа

Пользователь попадает в кабинет с ролью, быстрыми действиями и кратким обзором текущего состояния системы.

## Возможные ошибки

- неверный логин или пароль
- попытка открыть защищённую страницу без входа
- переход в раздел, который не разрешён текущей роли
