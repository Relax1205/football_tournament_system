# UI Tests

В этой папке находится базовая заготовка UI-автотестов для роли `Frontend & QA Lead`.

## Что покрыто

- позитивный вход в систему
- негативный вход в систему
- создание турнира организатором
- ввод результата матча судьёй
- проверка ограничения доступа для зрителя
- подача заявки на турнир тренером

## Стек

- Selenium WebDriver
- Node.js

## Подготовка

1. Запустить frontend локально.
2. Убедиться, что установлен браузер и драйвер для выбранного браузера.
3. Установить зависимости проекта через `npm install`.

## Запуск

```bash
UI_BASE_URL=http://localhost:3001 UI_BROWSER=chrome npm run test:ui
```

## Ограничения

- тесты рассчитаны на demo-данные и текущую структуру формы
