# UI Tests

В этой папке лежат Selenium UI-тесты для пользовательских сценариев в актуальном интерфейсе.

## Что покрыто

- позитивный вход в систему
- негативный вход в систему
- регистрация нового viewer-пользователя
- удаление пользователя администратором
- проверка центра уведомлений: выпадающий список, открытие сообщения по клику, отметка прочитанным, удаление
- создание турнира организатором
- ввод результата матча судьёй
- валидация минуты гола
- проверка read-only режима для зрителя
- подача заявки на турнир тренером
- проверка локализации дат и ссылок на экспорт

## Стек

- Selenium WebDriver
- Node.js

## Подготовка

1. Поднять backend и frontend локально или через Docker.
2. Убедиться, что доступны браузер и драйвер для выбранного браузера.
3. Установить зависимости проекта через `npm install`.

## Запуск

```bash
UI_BASE_URL=http://localhost:3000 UI_API_BASE_URL=http://localhost:4000/api UI_BROWSER=chrome npm run test:ui
```

## Замечания

- тесты используют demo-аккаунты из seed и создают собственные уникальные данные для регистрации и турнирных сценариев
- ожидания привязаны к текущим элементам интерфейса, а не к старому блоку `Быстрые действия`
